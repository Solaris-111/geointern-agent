## 路线详情

### 路线1：踏勘路线 (p81)
- **目的**：了解全区地质概况，建立整体认识
- **路线**：乘车环线，全区骨干路线
- **内容**：远观地质格局，识别主要地层单元和构造轮廓
- **提示**：第一天的路线，以建立空间感为主

### 路线2：八角寨—拴马庄桥 (p83)
- **主题**：中元古代地层观察
- **交通**：周口店→一号防空洞
- **观察内容**：
  1. 观察认识中元古代蓟县系地层：雾迷山组(Jxw)、洪水庄组(Jxh)、铁岭组(Jxt)
  2. 识别白云岩、千枚岩、板岩等岩性
  3. 观察叠层石化石
  4. 地层接触关系：整合 vs 平行不整合

### 路线3：黄院东山梁 (p86)
- **主题**：下古生界地层观察
- **观察内容**：
  1. 寒武系：府君山组(Cf)→馒头组(Ctzm)→徐庄组(Czx)→张夏组(Cz)
  2. 奥陶系：冶里组(Oy)→亮甲山组(Ol)→马家沟组(Om)
  3. 豹皮灰岩、鲕粒灰岩、竹叶状灰岩识别
  4. 三叶虫化石采集
  5. 地层划分标志层的确定

### 路线4：太平山南坡 (p88)
- **主题**：上古生界地层观察
- **观察内容**：
  1. 本溪组(C₂b)：平行不整合于马家沟组之上，底部红柱石角岩
  2. 太原组(C₂t)：砂泥互层，含煤线，植物化石
  3. 实测地层剖面（附图III）

### 路线5：太平山北坡 (p90)
- **主题**：上古生界地层+构造观察
- **观察内容**：
  1. 山西组(P₁s)、杨家屯组(P₁y)
  2. 豆腐块砂岩
  3. 北坡与南坡地层对比
  4. 实测信手剖面

### 路线6：房山岩体+热接触变质岩 (p93)
- **主题**：侵入岩及其接触变质带
- **路线**：探矿厂→官地→羊屎沟
- **观察内容**：
  1. 房山复式岩体：石英闪长岩→花岗闪长岩
  2. 边缘相/过渡相/中央相的岩性变化
  3. 暗色微粒包体（捕虏体）
  4. 接触变质带：近→远的矿物组合递变
  5. 堇青石角岩（菊花石）、红柱石角岩
  6. 侵入接触关系（图3-2、图3-3）

### 路线7：羊屎沟 (p95)
- **主题**：动力变质岩观察
- **观察内容**：
  1. 糜棱岩系列（初糜棱岩→糜棱岩→超糜棱岩）
  2. S-C组构识别
  3. 旋转残斑（σ型/δ型）
  4. 拉伸线理测量
  5. 动力变质与区域变质的区分

### 路线8：太平山背斜 (p97)
- **主题**：地层+构造综合观察
- **路线**：探矿厂→煤炭沟→太平山→探矿厂
- **观察内容**：
  1. 绘制煤炭沟→太平山信手剖面
  2. 太平山向斜核部地层（P₁y）和两翼地层
  3. 褶皱几何要素测量（枢纽、轴面、转折端）
  4. 伴生小构造（劈理、节理、小褶皱）

### 路线9：孤山口构造 (p99)
- **主题**：韧性剪切带入门
- **地点**：孤山口火车站
- **观察内容**：
  1. 雾迷山组(Jxw)硅质白云岩+钙质千枚岩
  2. 顺层韧性剪切特征
  3. 小型鞘褶皱

### 路线10：孤山口褶皱构造 (p100)
- **主题**：复杂褶皱分析
- **地点**：孤山口火车站北侧陡壁
- **观察内容**：
  1. 倒转—平卧褶皱序列
  2. "Z-M-S"型褶皱组合
  3. 斜卧褶皱、紧闭褶皱
  4. 劈理折射和劈理弯曲
  5. 窗棂构造

### 路线11：房山断裂构造 (p102)
- **主题**：脆性断裂观察
- **路线**：探矿厂→牛口峪→房山西
- **观察内容**：
  1. 一条龙—骆驼山近东西向正断层系
  2. 叠瓦状正断层剖面（图5-5）
  3. 断层产状测量和擦痕判断运动方向
  4. 周家坡弧形逆断层

### 路线12：逆冲推覆构造 (p104)
- **主题**：大型逆冲推覆系统
- **观察内容**：
  1. 老地层覆盖在新地层之上
  2. 飞来峰和构造窗
  3. 逆冲面的识别（角砾岩+擦痕+牵引褶皱）
  4. 推覆方向判断

### 路线13：164背斜+逆冲推覆 (p106)
- **主题**：褶皱-冲断组合
- **路线**：探矿厂→一条龙
- **观察内容**：
  1. 164背斜几何形态（联合剖面）
  2. 背斜内部小构造（火炬状节理、压溶劈理、同沉积褶皱）
  3. 逆冲推覆叠加关系

### 路线14：黄山店褶皱冲断 (p107)
- **主题**：大型弧形褶皱冲断带
- **路线**：探矿厂→黄山店→探矿厂
- **观察内容**：
  1. 两个互相叠置的弧形背斜和向斜
  2. 逆冲断层呈叠瓦状排列
  3. 信手剖面绘制（图5-20）

### 路线15：上方山岩溶地貌 (p108)
- **主题**：岩溶地貌+独立观察
- **路线**：圣水峪→上方山→云水洞
- **观察内容**：
  1. 碳酸盐岩岩溶地貌（溶洞、石芽、落水洞）
  2. 云水洞内部形态
  3. 岩溶与新构造运动的关系
  4. 独立地质观察练习

### 路线16：独立填图实践 (p110)
- **主题**：综合独立实践
- **内容**：
  1. 给定区域独立地质填图
  2. 观察点定点+产状测量+岩性描述
  3. 绘制地质平面图+信手剖面
  4. 编写路线地质报告
  5. 综合考核

## 与峨眉山路线对比

| | 周口店 | 峨眉山 |
|------|--------|--------|
| 路线数 | 16条 | 5条 |
| 地层时代跨度 | 太古宇→第四系 | 二叠系→白垩系 |
| 岩浆岩 | 房山复式岩体（闪长岩→花岗岩） | 玄武岩+少量花岗岩 |
| 变质岩 | 三种类型齐全 | 极少 |
| 构造 | 韧性剪切带+逆冲推覆 | 简单褶皱+断层 |
| 特色 | 变质分带+侵入分相 | 岩溶+沉积构造 |
