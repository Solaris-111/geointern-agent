## 物理成因沉积构造

### 层理类型

| 层理 | 特征 | 沉积环境 |
|------|------|---------|
| **水平层理** | 细层平直、平行层面 | 低能静水（深湖/深海/潟湖） |
| **平行层理** | 粗粒岩中的水平层理 | 高流态（河道/海滩） |
| **板状交错层理** | 前积层平直、层系界面平行 | 河道/三角洲 |
| **槽状交错层理** | 前积层弯曲、层系界面下凹 | 河道（较强水动力） |
| **楔状交错层理** | 层系厚度向一侧减薄 | 潮汐/海滩 |
| **爬升波纹层理** | 波纹向上迁移叠加 | 快速沉积（浊流/泛滥平原） |
| **粒序层理** | 粒度向上变细（正粒序）或变粗（逆粒序） | 浊流（正）/风暴（逆） |

### 层面构造

| 构造 | 特征 | 指示 |
|------|------|------|
| **对称波痕** | 波峰尖、波谷圆 | 双向水流（潮汐/波浪），波脊线∥岸线 |
| **不对称波痕** | 波峰一侧陡一侧缓 | 单向水流，陡坡指向下游 |
| **干涉波痕** | 两组波痕交叉 | 流向变化（潮间带/浅水） |
| **泥裂** | 多边形干裂纹 | 暴露环境（潮上带/河漫滩），指示顶面 |
| **雨痕/冰晶痕** | 小圆坑/针状印模 | 陆上暴露 |
| **槽模/沟模** | 底面的凸起/凹槽 | 浊流冲刷（底层面），指示水流方向 |
| **重荷模** | 砂层底面不规则瘤状凸起 | 砂覆泥，密度倒转→沉陷（指示底面） |
| **火焰构造** | 泥质向上刺入砂层 | 与重荷模共生，指示底面 |

### 变形构造

| 构造 | 特征 | 成因 |
|------|------|------|
| **包卷层理** | 层内褶曲、不涉及上下层 | 沉积物液化→滑动 |
| **滑塌构造** | 层间褶皱、断裂 | 水下斜坡滑动 |
| **砂岩岩脉** | 砂质充填裂隙 | 地震/液化注入 |
| **碟状构造** | 碟形凹面朝上 | 孔隙水向上逃逸 |

### 浊积岩鲍马序列（Bouma Sequence）

一次浊流事件自下而上的完整序列：

| 段 | 特征 | 沉积机制 |
|----|------|---------|
| Ta | 块状 / 正粒序砂岩 | 高密度浊流快速沉积 |
| Tb | 平行层理砂岩 | 上部流态 |
| Tc | 交错层理 / 波纹层理 | 下部流态 |
| Td | 水平层理粉砂岩 | 悬浮沉降 |
| Te | 泥质段 | 细粒悬浮沉降 |

> 完整 Ta→Te 少见，常缺失下部（Ta）或上部（Te）

## 化学成因沉积构造

| 构造 | 特征 | 指示 |
|------|------|------|
| **缝合线** | 锯齿状接缝，常含泥质/有机质 | 压溶作用，指示层面方向 |
| **结核** | 球状/椭球状集合体 | 成岩期化学沉淀（钙质/硅质/黄铁矿） |
| **叠锥构造** | 锥形层叠 | 成岩压溶 |
| **鸟眼构造** | 毫米级不规则孔洞，被亮晶方解石充填 | 潮间-潮上带暴露 |

## 生物成因沉积构造

| 构造 | 特征 | 指示 |
|------|------|------|
| **虫迹/虫管** | 垂直/水平管状构造 | 浅水（垂直）/深水（水平） |
| **生物扰动** | 层理被生物活动破坏 | 富氧环境，生物活动强度 |
| **叠层石** | 明暗相间的藻纹层 | 浅水（潮间带为主） |
| **植物根迹** | 根状构造穿过层理 | 陆地/沼泽环境 |

## 用沉积构造判断地层层序（顶底方向）

| 构造 | 顶面特征 | 底面特征 |
|------|---------|---------|
| **交错层理** | 前积层顶部被削截 | 前积层底部切线收敛 |
| **粒序层理** | 粗→细（正粒序的正常层序顶在上） | 细→粗（逆粒序） |
| **泥裂** | 裂口向上张开，呈V形 | 裂口向下收窄 |
| **重荷模** | — | 凸起在下层面 |
| **火焰构造** | — | 泥刺向上，在上层面 |

> **口诀**：交错层理削顶在顶，粒序粗下细上，泥裂V口朝天，重荷模疙瘩在底

## 古水流方向判断

| 构造 | 如何判断流向 |
|------|-------------|
| 交错层理 | 前积层倾向 = 水流方向 |
| 不对称波痕 | 陡坡方向 = 水流方向 |
| 槽模 | 凸起尖端 = 逆水流方向（水流从钝端来） |
| 砾石叠瓦 | 砾石长轴倾向 = 逆水流方向 |

## 峨眉山路线二实例

> 龙门硐电站→龙门硐口（三叠系沉积岩路线，8个观察点）

| 观察点 | 构造 | 特征 | 沉积环境 |
|--------|------|------|---------|
| 波痕 | 不对称波痕 | 飞仙关组砂岩层面 | 浅水→单向水流 |
| 虫迹 | 水平虫管 | 飞仙关组粉砂岩 | 较深水→低能 |
| 平行层理 | 细层平行 | 嘉陵江组灰岩 | 高流态浅水 |
| 斜层理 | 板状交错层理 | 飞仙关组砂岩 | 河道/潮汐水道 |
| 渠迹 | 冲刷充填构造 | 嘉陵江组灰岩顶面 | 潮汐水道冲刷 |
| 重荷模+火焰 | 砂层底面瘤状凸起+泥刺 | 飞仙关组砂泥互层 | 快速沉积→密度倒转 |
| 缝合线 | 锯齿状接缝 | 嘉陵江组灰岩中 | 压溶（成岩期） |
| 膏盐假晶 | 立方体/板状印模 | 嘉陵江组白云岩 | 蒸发环境（潮上带萨布哈） |

## 常见坑
- 用交错层理判断流向时把前积层倾向读反 → 削顶方向是顶，切线收敛方向是底
- 把构造节理当成泥裂 → 泥裂呈V字形、上宽下窄，充填物与上覆层一致
- 不分原生构造和次生构造 → 沉积构造必须形成于沉积-成岩期
- 忘了拍特写照片 → 沉积构造细节比全景重要
