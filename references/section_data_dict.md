# 信手剖面图数据字典

> 绘制前必须逐项确认。缺数据 → 问用户；数据异常 → 提醒后再画。
> 核心原则：**宁可少画，不要多画**——组厚度、岩层厚度不够时留空标注，不硬凑。

---

## A. 基础参数

| 参数 | 说明 | 示例 | 必填 |
|------|------|------|------|
| 路线编号 | L03 / L06 等 | L06 | ✓ |
| 剖面名称 | 如"官地—羊屎沟接触热变质带信手剖面图" | — | ✓ |
| 剖面走向 | 起点→终点方位角(°) | 330° (NW-SE) | ✓ |
| 水平比例尺 | 如 1:1000, 1:5000 | 1:1000 | ✓ |
| 垂直比例尺 | 如 1:1000（与水平一致=无放大） | 1:1000 | ✓ |
| 垂直放大倍数 | VE = 垂直比例尺分母 / 水平比例尺分母 | 1.0 | 自动算 |

---

## B. 地形数据

**最少 20-30 个控制点**才能绘制平滑准确的地形线。仅靠观察点（通常 5-10 个）完全不够。

| 参数 | 格式 | 说明 | 必填 |
|------|------|------|------|
| 控制点坐标 | `[ (x₁, y₁, z₁, 描述), ... ]` | 经纬度+高程+点位名称，沿剖面线排列 | ✓ |
| x坐标 | 沿剖面线的**累积水平距离**(m) | 起点=0, 后续点累加 | ✓ |
| 高程 | z(m)，每个控制点对应 | — | ✓ |
| 数据来源 | GPS实测 / SRTM DEM / 在线地图 | — | ✓ |

**控制点采集优先级：**

```
1. 实习观察点（GPS + 高程）          → 5-10 个，必须
2. KML 轨迹点等距采样                → 自动生成 10-20 个
3. 万维地图/天地图查找标志点位        → 补充 5-15 个
   · 山顶、垭口、沟谷底部 → 这些是地形转折点
   · 公路交叉口、桥梁、建筑物 → 标志明确，在线地图可查坐标+高程
   · 等高线拐点 → 坡度变化处必须有一个点
4. SRTM DEM 批量查询                → 对上述所有点统一核对高程
```

**在线地图获取坐标方法：**
- 天地图 (tianditu.gov.cn)：有等高线图层，直接读高程
- Google Earth：鼠标移到目标位置即可显示坐标+高程
- 奥维地图：手机端可在地图上打点导出坐标
- 百度/高德地图拾取坐标系统：搜标志地名 → 获取经纬度 → 用 SRTM 查高程

**验证规则：**
- 20 个点是硬底线。少于 20 → 问用户"你这条剖面上还有哪些标志性地物？"
- 高程变化是否合理？（相邻点高程差不应突变超过 50m/100m 水平距离，除非是悬崖）
- x 坐标是否单调递增？（沿剖面方向应是累加的）
- 地形转折点（山顶/谷底/坡折）是否都有控制点？漏了 → 地形线会在转折处失真
- 如果高程数据缺失某个控制点 → 问用户，或从在线地图估算并标注"推测"

## C. 产状数据

### C1. 层理/片理产状（控制地层界线地下延伸）

| 参数 | 格式 | 说明 | 必填 |
|------|------|------|------|
| 倾向 | ° (0-360) | — | 每组/每点至少 1 组 |
| 倾角 | ° (0-90) | 真倾角 | ✓ |
| 所属组 | 地层代号 | 如"JxW""QbX" | ✓ |
| 测量位置 | 在哪个控制点附近 | — | ✓ |
| 产状类型 | 层理 / 片理 / 片麻理 | — | ✓ |

**转换为视倾角：**
```
视倾角 δ' = arctan( tan(δ) × sin(θ) )
   δ = 真倾角，θ = 剖面走向与岩层倾向的夹角
```
- θ 怎么算：θ = | 剖面走向方位角 − 岩层倾向 |
- δ' ≤ δ，如果 δ' < 5° → 地下延伸线近乎水平，可能不合理 → 提醒用户

**验证规则：**
- 每个组至少有一个产状，零产状时地下界线无法延伸 → 问用户"XX组有没有量产状？"
- 同一组的多个产状应该相近（差异 >30° 时提醒"XX组产状变化大，有褶皱/断层吗？"）
- 如果某组没有产状 → 用相邻组的产状插值，标注"推测"

### C2. 断层产状

| 参数 | 格式 | 说明 | 必填 |
|------|------|------|------|
| 断层面倾向 | ° | — | 仅在断层接触点时 |
| 断层面倾角 | ° | — | ✓ |
| 断层位置 | 距起点x(m) | — | ✓ |

### C3. 褶皱要素（如有）

| 参数 | 格式 | 说明 | 必填 |
|------|------|------|------|
| 褶皱位置 | 距起点x(m) | **水平坐标，沿剖面线方向** | ✓ |
| 轴面倾向 | ° | — | 有褶皱时 |
| 轴面倾角 | ° | — | ✓ |
| 枢纽倾伏向 | ° | — | 有褶皱时 |
| 枢纽倾伏角 | ° | — | ✓ |
| 两翼产状 | 各一组倾向/倾角 | 分别记左翼和右翼 | ✓ |

**重要：** 褶皱轴线的水平坐标必须精确到控制点之间的距离级别（±5m）。用 GPS 或从 KML 轨迹上标定。轴线位置错了，整个剖面的构造解释就错了。

## D. 地层数据

### D1. 各组参数

| 参数 | 格式 | 说明 | 必填 |
|------|------|------|------|
| 组名 | 中文名 + 代号 | "雾迷山组 (JxW)" | ✓ |
| 真厚度 | m | 从路线资料或实测 | 尽量 |
| 视厚度 | m | 沿剖面的出露宽度 | 自动算 |
| 关键岩性 | 描述 | "硅灰石透闪石大理岩" | ✓ |
| 统一产状 | 倾向∠倾角 | 代表该组沿剖面方向的视倾角 | ✓ |

### D2. 真厚度 → 水平出露宽度换算

```
水平宽度 = 真厚度 / sin(δ')  （δ' = 视倾角，°）
```

- 如果 δ' < 5° → 水平宽度极大（>真厚度×11），可能是水平岩层或产状有问题 → **提醒用户确认**
- 如果真厚度未知 → 问用户，或用 KML 控制点间距估算（标注"估算"）

**"宁少勿多"规则：**
- 真厚度确认了 → 画完整厚度
- 真厚度不确定 → 只画到控制点覆盖的范围，不往后硬延
- 顶底不全的组 → 标注"未测至顶/底"

### D3. 地层韵律规则

**规则1：所有地层组默认走 for 循环，不用单一填充。**

- 同组只有一种岩性 → **厚层-薄层交替**（厚层 55%+薄层 45%，默认中层 3m/旋回）
- 同组≥2种岩性 → 默认**互层**（每种岩性等比例轮流）
- 除非该组内的变化是特殊构造现象或层间带，否则不单独处理

**规则2：旋回厚度**

- 用户指定 `rhythm_cycle_m` → 优先使用
- 未指定 → 默认中层 3m/旋回
- 旋回数 = int(真厚度 / 旋回厚度)，余数丢弃 → **宁可少画**

**规则3：岩性自动拆分**

- 岩性名含"夹""与""和""+" → 自动拆分为多种岩性
- 修饰词（薄层/中层/厚层/泥质/钙质等）自动过滤
- 拆分后有≥2种有效岩性名 → 互层；≤1种 → 厚层-薄层

### D4. 地层叠置顺序

| 参数 | 格式 | 说明 | 必填 |
|------|------|------|------|
| 从老到新 | 列表 | `[ArG, JxW, JxH, JxT, QbX, QbC]` | ✓ |
| 接触关系 | 每两个相邻组之间 | 整合 / 平行不整合 / 角度不整合 / 断层 | ✓ |

## E. 接触界线规范

**绘制方案阶段：所有接触界线和组间界线先用红色标注。** 在示意图/草图上用红色线段标出每条界线的位置和类型，用户确认后再用正式线型绘制。

| 接触类型 | 线型 | 颜色 | 说明 |
|----------|------|------|------|
| **绘制方案草图** | 标注线 | **红色** | 所有界线先标红，确认后再正式画 |
| 整合接触 | 实线，0.8pt | 黑 | 正常沉积序列 |
| 平行不整合 | 波状线，1.0pt | 黑 | 上下产状一致，有古风化壳/地层缺失 |
| 角度不整合 | 波状线 + 上覆地层截切下伏地层不同层面 | 黑 | 上下产状不一致 |
| 正断层接触 | 虚线或粗线 1.5pt + 断层符号 | 黑 | 上盘下降 |
| 逆断层接触 | 虚线或粗线 1.5pt + 断层符号 | 黑 | 上盘上升 |
| 侵入接触 | 不规则锯齿线，1.2pt | 黑 | 岩浆侵入围岩 |

**组间界线 = 同一组内不同岩性段的界线**，同样需要标注。不要只标组与组之间的接触面。

**界线地下延伸规则：**
- 地下延伸线使用该组视倾角计算
- 延伸深度：默认到图框底 / 或被下一断层截断
- 不整合面地下：被不整合面截断的下伏地层界线不到达不整合面之上

## F. 绘制前检查清单

```
□ A. 基础参数齐全？（走向、比例尺、名称）
□ B. 每个控制点有 x(m) 和 z(m)？
□ C. 每个组有至少一个产状？
□ C. 所有产状已换算为视倾角？
□ D. 各组真厚度已知？未知的标注了吗？
□ D. 地层叠置顺序和接触关系确认？
□ E. 每个接触面已标注类型？
□
□ 验证:
□ 地形高程无异常跳变？
□ 视倾角没有接近 0°（<5°）或 90°的异常？
□ 同一组多个产状无 >30°矛盾？
□ 真厚度换算的水平宽度与 KML 控制点间距大致相符？
```
