# 岩性-花纹映射表

> 岩性花纹图例（地质制图标准填充）
> 用法：`engine.add_formation(code, name, dist, lithology="岩性名")`
> hatch 字段支持叠加，如 `"//.."` = 斜线+点

核心规则：
- **灰岩** → 细密平行斜线 `////`
- **白云岩** → 均匀点/小圆圈 `..`（标准填充，非砖块纹）
- **砂岩** → 点密度区分粗细 `o.` / `..` / `....`
- **页岩/板岩** → 平行横线 `---`
- **千枚岩** → 竖线 `||`
- **花岗岩** → 十字 `++`

## 沉积岩

| 岩性 | hatch | 说明 |
|------|-------|------|
| 砾岩 | `"oO"` | 大圆+小圆，代表砾石 |
| 粗砂岩 | `"o."` | 稀疏大点 |
| 中砂岩 | `".."` | 均匀点 |
| 细砂岩 | `"...."` | 密集细点 |
| 粉砂岩 | `"...."` | 极密细点，与细砂岩同hatch，靠密度区分 |
| 石英砂岩 | `"o"` | 圆圈，代表磨圆好的石英颗粒 |
| 长石砂岩 | `"+."` | 十字+点 |
| 泥岩 | `"---"` | 水平密线 |
| 页岩 | `"---"` | 水平线，可加 `\|` 表页理 |
| 碳质页岩 | `"---|---"` | 水平线+间断竖线 |
| 钙质页岩 | `"--//"` | 水平线+斜线 |
| 灰岩 | `"////"` | 砖块纹（斜45°方格） |
| 白云岩 | `"xxxx"` | 砖块纹（斜135°方格，与灰岩正交） |
| 含燧石灰岩 | `"//.."` | 砖块纹+点 |
| 含燧石白云岩 | `"xx.."` | 白云岩纹+点 |
| 鲕粒灰岩 | `"//o"` | 砖块纹+小圈 |
| 竹叶状灰岩 | `"//\\\\"` | 双向斜线 |
| 豹皮灰岩 | `"//o."` | 砖块纹+稀疏大点 |
| 泥质条带灰岩 | `"//--"` | 斜线+水平线 |
| 纹带灰岩 | `"//\|\|"` | 斜线+竖线 |
| 泥灰岩 | `"--//"` | 水平线+斜线 |
| 白云质灰岩 | `"//xx"` | 灰岩底+白云岩叠 |
| 大理岩 | `"//.."` | 砖块纹+点 |
| 砂糖状大理岩 | `"..//"` | 点+砖块纹 |

## 变质岩

| 岩性 | hatch | 说明 |
|------|-------|------|
| 板岩 | `"---"` | 细水平线 |
| 千枚岩 | `"\|\|"` | 竖线，代表千枚理 |
| 千枚状板岩 | `"-\|"` | 水平+竖线交织 |
| 片岩 | `"///"` | 斜线，代表片理 |
| 片麻岩 | `"///++"` | 斜线+十字 |
| 角岩 | `"++"` | 十字交叉 |
| 变砂岩 (变质石英砂岩) | `"o"` | 同石英砂岩 |
| 糜棱岩 | `"--//"` | 水平+斜线，代表流动构造 |

## 岩浆岩

| 岩性 | hatch | 说明 |
|------|-------|------|
| 花岗岩 | `"++"` | 十字 |
| 花岗闪长岩 | `"++.."` | 十字+点 |
| 闪长岩 | `"+x"` | 十字+叉 |
| 辉长岩 | `"xx"` | 密集叉 |
| 辉绿岩 | `"vv"` | V 形 (需自定义) |
| 玄武岩 | `"xx\|\|"` | 叉+竖线 (柱状节理) |
| 安山岩 | `"+\|"` | 十字+竖线 |
| 流纹岩 | `"//\|"` | 斜线+竖线 (流纹构造) |
| 凝灰岩 | `"...\|\|"` | 密点+竖线 |

## 特殊构造

| 构造 | hatch | 说明 |
|------|-------|------|
| 不整合面 | 无花纹，红色波浪线 | 手动绘制 |
| 断层 | 无花纹，粗实线+锯齿 | 手动绘制 |
| 古风化壳 | 无花纹，不规则黑块 | 手动绘制 |
| 覆盖层/浮土 | 空白或 `"..."` | 稀疏点 |

## 用法

调用时只填岩性名，引擎自动匹配花纹。例如：

```python
engine.add_formation("JxW5", "雾迷山组", 0.0, lithology="含燧石白云岩")
engine.add_formation("JxH",  "洪水庄组", 0.6, lithology="千枚岩")
```

不按组名填——岩性重复的组自动用同一个花纹。

## matplotlib hatch 速查

| 字符 | 图形 | 代表 |
|------|------|------|
| `/` | 斜线 / | 灰岩底纹 |
| `\` | 反斜线 \ | 辅助纹 |
| `x` | 交叉 × | 白云岩/辉长岩 |
| `+` | 十字 + | 花岗岩 |
| `o` | 小圆 ○ | 砂岩颗粒/鲕粒 |
| `O` | 大圆 | 砾石 |
| `.` | 小点 | 细砂岩/粉砂岩 |
| `-` | 横线 | 页岩/板岩 |
| `\|` | 竖线 | 千枚岩/片理 |
| `*` | 星号 | 特殊标记 |

> 叠加示例: `"//o"` = 斜线方格 + 小圆圈 = 鲕粒灰岩
