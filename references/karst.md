# 岩溶地貌（喀斯特）

> 通用地质知识，可参考开源教材 OpenGeology / LibreTexts 的 Karst & Groundwater 章节
> 用于：峨眉山路线四（四溪沟）、周口店路线15（上方山岩溶地貌）

---

## 岩溶作用与形成条件

**岩溶（喀斯特）作用**：可溶性岩石被地表水、地下水化学溶蚀为主，辅以机械侵蚀、重力崩塌，形成的地表和地下独特地貌。

三个基本条件缺一不可：

| 条件 | 说明 |
|------|------|
| ① 可溶性岩石 | 灰岩（CaCO₃）为主，其次白云岩、大理岩、石膏、盐岩 |
| ② 具溶蚀能力的水 | 含 CO₂ 的地下水/地表水，酸性越强溶蚀越强 |
| ③ 岩石透水性 | 节理、裂隙、层面为水的通道，构造越发育岩溶越发育 |

## 化学机制（可逆反应）

```
CaCO₃ + H₂O + CO₂  ⇌  Ca(HCO₃)₂
  方解石              重碳酸钙（可溶）
```

- **正向（→）**：水中 CO₂ 多 → 溶解灰岩 → 形成溶洞、溶沟
- **逆向（←）**：CO₂ 逸出（进入洞穴后压力/温度变化）→ CaCO₃ 重新沉淀 → 形成钟乳石、石笋

## 地表岩溶地貌

| 地貌 | 特征 | 成因 |
|------|------|------|
| 石芽 / 溶沟 | 溶沟为槽、石芽为脊，几 cm～几 m | 地表水沿裂隙溶蚀 |
| 溶蚀洼地 | 近圆形负地形 | 溶蚀汇聚 |
| 漏斗 / 落水洞 | 竖井状，地表水由此转入地下 | 溶蚀 + 塌陷 |
| 干谷 | 谷底常年无水，仅雨季有水 | 地表水已转入地下 |
| 峰林 / 峰丛 | 锥状、塔状山峰群 | 长期溶蚀残余 |

## 地下岩溶地貌

| 地貌 | 特征 |
|------|------|
| 溶洞 | 地下水沿构造面溶蚀形成的洞穴 |
| 钟乳石（洞顶） | 向下生长，滴水 CaCO₃ 沉淀 |
| 石笋（洞底） | 向上生长，对应上方钟乳石 |
| 石柱 | 钟乳石 + 石笋上下连接成柱 |
| 石幔 / 石帷幕 | 沿洞壁流下的片状沉淀 |
| 地下河 | 溶洞内流动的地下水，可发育暗河 |

## 岩溶发育阶段（旋回）

1. **幼年期**：以地表水溶蚀为主，形成石芽、溶沟
2. **青年期**：落水洞、漏斗发育，地表水大量转入地下
3. **壮年期**：地下河、溶洞发育成熟，暗河系统完善
4. **老年期**：洞顶塌陷，地表残留峰林、孤峰

## 多层溶洞与新构造运动（重点）

- 溶洞常沿某一高程**成层分布** → 该高程曾是当时的**地下水面（潜水面）**
- **多层溶洞** = 地壳发生过多次**间歇性抬升**的记录
- 每层溶洞的高程，对应一次构造稳定期；层间高差对应抬升幅度

## 野外观察要点（岩溶路线）

1. 溶洞形态 + 发育层位（出露于哪个地层、哪个高程）
2. 石芽、石幔、钟乳石/石笋的形态与生长方向
3. **多层溶洞的高程测量** → 判断新构造运动抬升次数与幅度
4. 落水洞与干溶洞的空间关系（地表水如何转入地下）
5. 岩溶与节理、断层的关系（溶蚀是否沿构造面优选发育）
