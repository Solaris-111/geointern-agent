## 构造符号

| 符号 | 含义 |
|------|------|
| 实线 + 三角（三角在上盘） | 逆断层 |
| 实线 + 短齿（齿在下盘） | 正断层 |
| 半箭头 | 平移断层 |
| ⊥ 或 ┬ | 产状（长线=走向，短线=倾向，数字=倾角） |
| 背斜轴线 + → | 背斜（箭头=枢纽倾伏方向） |
| 向斜轴线 + → | 向斜 |
| 封闭圈 + 老地层 | 飞来峰 |
| 开口圈 + 新地层 | 构造窗 |
| 波浪线 | 角度不整合 |
| 虚线 | 平行不整合 |
| 点划线 | 推测界线 |

## 地质点编号规范

| 代码 | 含义 |
|------|------|
| D | 地质观察点（如 D0001、D0704） |
| L | 路线（如 L01、L02） |
| P | 实测剖面 |
| B | 岩石标本 |
| HS | 化石 |
| DB | 定向标本 |
| BF | 薄片 |
| GP | 光谱分析 |
| GS | 构造标本 |
| Z | 野外照片 |
| S₀ | 原始层理 |
| S₁, S₂... | 面理（按形成先后编号） |
| F | 断层 |
| b | 枢纽 |
| L | 线理 |

## 常见坑
- 岩性花纹不要自己发明——有标准图例，照着画
- 剖面图上不同岩性接触处的花纹要对齐
- 构造符号大小要统一，特别是产状符号
- 忘记在图例中列出所有用到的花纹
