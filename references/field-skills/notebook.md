# 野簿记录规范

> 野簿记录规范（通用）+ 周口店/峨眉山实习要求

---

## 记录基本原则

- 观察和测量之后，必须用**文字、图示、素描、摄影、实物**等形式记录
- 野簿是野外工作的**第一手原始资料**，不得事后修改
- 记录应**格式统一、字迹工整、图文并茂**
- 不同路线或不同观察点的记录应**另起一页**
- 所有符号和花纹应用黑墨水清绘，批注用红墨水
- **GPS坐标每个点必记**——这是野簿最硬的数据，照片丢了还能凭坐标回去找

---

## 每条路线开头格式

每条路线在新的一页开始，按以下顺序写：

```
202X年X月X日  星期X  天气：XX
地点：XX省XX市XX区XX（具体到乡镇/村）

路线：起点 → 途经点 → 途经点 → 终点（用→连接）
路线号：LXX

任务：
① 观察/掌握/认识……（动词开头）
② 绘制……（图件任务）
③ 定地质点并填制/勾绘路线地质图（如适用）
```

**关键规则：**
- **路线名称和任务必须从实习路线要求逐条抄录**，不自己编
- 任务2-5条，动词开头（观察/掌握/绘制/采集/分析/定）
- 路线号写 `路线号 LXX`，不写 `路线编号：LX`

**实例（周口店L12，来自标准格式模板）：**
```
2003年8月15日  星期五  天气  晴
地点：北京市房山区周口店

路线：基地 → 三不管沟 → 骆驼山南侧 → 牛口峪水库 → 基地
路线号：L12

任务：
① 观察描述Pt₃j—∈₁f地层层序、岩性组合及其接触关系；
② 绘制地层信手剖面图；
③ 定地质点并填制、勾绘路线地质图。
```

## 每个观察点记录格式（按顺序，严格遵守）

### 1. 点号
- 格式：`D` + 路线号（2位）+ 序号（2位），如 `D1203`（路线L12第3个点）
- 单独一行，写 `点号：DXXXX`
- **不要跳号**

### 2. 点位
- 观察点在实地中的具体位置，用**距离+参照物+方向**描述
- 格式：`点位：位于XX（参照物）XX°方向约XXm处的XX（地貌特征）`
- 示例：`点位：位于山顶庙165°方向约350m处的陡壁下`
- **文字位置描述优先于GPS**——GPS坐标单独记在"坐标"行

### 3. 坐标
- 单独一行，格式：`坐标：X: XX XX⁰⁰⁰  Y: XX XX⁰⁰`（上方小字为高程）
- GPS坐标是一个点的身份证——野簿丢了可以凭坐标重新找到
- 周口店填图训练中GPS**必须记录**

### 4. 点性
- **单独一行**，写 `点性：……`
- **必须使用实习指定的原话**，不是自己概括的类型名
- 示例：`点性：景儿峪组（Pt₃j）与府君山组（∈₁f）分界点`（不是「地层分界点」）
- 示例：`点性：铁岭组一段（Jxt¹）与洪水庄组（Jxh）岩性分界点`（不是「岩性控制点」）
- 点性决定了下面描述的重点方向，不能省略、不能自己编

### 5. 描述（核心内容，按方向分述）

**基本格式：**

```
描述：
  点南为：……
    产状性质：XX ∠ XX
  点北为：……
    产状性质：XX ∠ XX
  接触关系/构造判断：……
    证据：……
```

**地层分界点标准写法：**
1. 先说点南、点北各是什么组、什么岩性
2. 各侧的产状性质（`倾向 ∠ 倾角`）
3. 接触关系及证据
4. 如有素描图，写 `（图X-X）`

**实例（来自标准格式模板）：**
```
描述：
  点南为：景儿峪组（Pt₃j）……（岩性描述）
    产状性质：165 ∠ 24
  点北为：府君山组（∈₁f）……（岩性描述）
    产状性质：162 ∠ 30
  景儿峪组（Pt₃j）与府君山组（∈₁f）为平行不整合接触（图13）。
```

**岩性点描述——岩石全名格式：** `颜色 + 构造 + 结构 + 主要矿物成分 + 岩石名称`
- 示例：`浅灰色中厚层状中粗粒变质石英砂岩`

**详细描述顺序：**
1. 说明该点所处的岩石地层单位及其部位
2. 岩石颜色——**必须区分新鲜面色和风化面色**
3. 结构：粒度、分选、磨圆、胶结物、胶结程度
4. 构造：层理类型、层厚
5. 矿物成分及目估百分含量
6. 若为厚层均一岩性，先总述再分层细述
7. 观察范围内岩性的纵横向变化

**构造点描述——断层：**
1. 断层名称 + 两盘地层单位及岩性
2. **断层面产状**（`倾向 ∠ 倾角`）
3. **断层证据至少列2项**（擦痕/阶步/断层角砾岩/牵引褶皱）
4. 断层性质（正/逆/平移）+ 判断依据
5. 断层规模（破碎带宽度、断距估算）

**构造点描述——褶皱：**
1. 褶皱名称 + **至少5个产状**（两翼×2 + 轴面 + 枢纽 + 转折端）
2. 翼部/核部岩石地层单位及岩性
3. 配合素描图

### 6. 点间记录

两个观察点之间的沿途观察，不另立新点号：

```
点间：向XX方向观察：
  0～XXm为：……（岩性描述）
    产状性质：XX ∠ XX
  XX～XXm为：……（岩性描述）
    产状性质：XX ∠ XX
```

- 用距离范围（m）划分岩性段
- 产状变化处要记
- 点间记录夹在两个观察点之间，不另起新点号

## 产状记录格式

- 每个产状写 `产状性质：倾向 ∠ 倾角`，**不写度符号°**
- 格式：`产状性质：165 ∠ 24`（空格 + ∠ + 空格）
- 示例：`产状性质：245 ∠ 47`
- 示例：`断层面产状性质：60 ∠ 55`
- **产状旁用红笔标注「产状、标本、照片等」**（红虚线框）
- **标注产状所属地层单位及部位**——裸数字没有地质意义
- 相邻点产状有对比关系时，用红笔箭头连接标注

## 标本采集与登记

- 每条路线必须记录采集标本数量（包括0块）
- 数量为0时要说明原因，如"本路线禁止采集"
- 采集的标本当场编号、当场登记，不要回来再补

**标本登记格式：**

| 编号 | 名称 | 采集地点 | 层位 | 日期 |
|------|------|----------|------|------|
| B001 | 豹皮灰岩 | D0303, 黄院东山梁 | 府君山组（Cf） | 7.7 |

---

## 素描图规范

- 每张素描图必须标注：**图号、图名、比例尺、方向、图例**
- 图号按路线编号：`图2-1`（L02路线第1张素描）
- 比例尺用实际尺寸标注，如 `10m`、`50cm`
- 图例中所有出现的地层代号和岩性符号都要说明
- 素描图不作为孤立附图，必须在正文中引用——描述写"作有图2-1"

---

## 路线小结

- 每条路线观察结束后**当天**写小结，不要堆到最后
- 内容包括以下**五项**，不能只写一两句：

```
小结：
① 路线基本情况：全长约X km，共记录DXX至DXX共X个点，采集标本X块，
   素描图X张，信手剖面图X幅
② 主要成果：今天观察到了什么、掌握了什么知识
③ 存在问题：哪些内容没弄明白、需要查阅资料或请教老师
④ 思考题：针对本路线现象提出1-3个问题并给出自己的初步回答
⑤ 自我评估：自己的记录质量、描述能力、野外技能方面的进步与不足
```

**优秀实例（周口店L01小结）：**
```
① L01路线全长约3km，共记录D0101至D0110十个点，素描图1幅，地形剖面图1幅。
② 观察到多种构造现象，学习了原始岩层的识别方法和微地貌定点法。
③ 意识到自己对于岩石判别、岩性描述的熟练度严重不足。
④ 思考题：向斜成山还是向斜成谷？——向斜顶部受张力发生张裂，易受侵蚀形成谷地；
   向斜槽部受挤压岩层坚硬，发育成山岭，称为地形倒置。
```

## 图件整理

- 清绘地形图上的地质界线、观测点、产状符号
- 地质点/泉/采样点圈直径 1.5-2mm
- 产状符号字高 2-3mm，**字头朝北**
- 地质界线圆滑、产状准确
- 野簿中绘制的素描图/信手剖面图/示意图应规范清绘

## 常见坑（按严重程度排序）

| 严重度 | 问题 | 怎么避免 |
|--------|------|---------|
| **致命** | GPS坐标没记 | 每个观察点第一件事——记坐标（X/Y格式） |
| **致命** | 点性自己编、不按实习要求 | 点性必须写实习指定原话——「XX组与XX组分界点」不是「地层分界」 |
| **致命** | 产状没标所属层位 | 每个产状前必须写地层单位：`铁岭组三段（Jxt³）产状性质：245 ∠ 47` |
| **严重** | 路线和任务自己编 | 路线头（路线名称、任务清单）从实习路线要求逐条抄录 |
| **严重** | 日期天气留空 | 每页开头第一行填日期天气，养成肌肉记忆 |
| **严重** | 素描图没标比例尺 | 每张图检查：图号+图名+比例尺+方向+图例 |
| **严重** | 标本编号混乱或漏记 | 野外当场编号，回驻地就登记 |
| **中等** | 把风化色当新鲜色写 | 描述颜色时明确说"新鲜面呈XX色，风化面呈XX色" |
| **中等** | 把杏仁状充填当斑晶 | 玄武岩的气孔充填物不是斑晶——看边界是否截然 |
| **中等** | 岩性描述太笼统 | 不能说"砂岩"，必须说"灰白色中粒长石石英砂岩" |
| **中等** | 忘了写路线小结 | 每天野外回来当天写，别堆到最后——忘记70% |
| **中等** | 产状格式不对 | 用 `245 ∠ 47`，不写 `245°∠47°`，不加度符号 |
| **轻微** | 观察点之间没留空行 | 点与点之间留3-5行空行，方便补充点间记录 |
| **轻微** | 不同路线接在同一页 | 每条路线新起一页 |
| **轻微** | 没有点间记录 | 点与点之间记沿途岩性变化和产状 |

## 峨眉山 vs 周口店野簿差异

| 方面 | 峨眉山 | 周口店 |
|------|--------|--------|
| 路线数 | 5条 | 16条 |
| 每条点数 | 3-6个 | 4-10个 |
| 重点 | 岩浆岩（玄武岩）鉴定、沉积相分析、岩溶地貌 | 完整地层序列、多期构造叠加、变质岩分带、岩体接触关系 |
| 构造 | 断层+节理统计为主 | 褶皱+断层+韧性剪切带+推覆构造，产状密度要求更高 |
| 图件 | 柱状图+信手剖面+节理玫瑰花图 | 柱状图+信手剖面+联合剖面+构造纲要图 |
| GPS坐标 | 建议记录 | **必须记录**（填图训练需要） |
