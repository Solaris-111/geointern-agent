## 一、信手地质剖面图

### 什么时候画
- 文字描述无法准确表达地质结构的空间关系时
- 需要展示地层叠置序列、构造形态、接触关系时
- 每条路线的关键观察段

### 画图步骤

**1. 选定剖面线**
- 大致垂直于岩层走向
- 涵盖路线上要展示的关键地质体
- 起止点选在明显的地形地物处

**2. 确定比例尺**
- 水平比例尺：1:500 ~ 1:5000
- 垂直比例尺可以与水平相同，也可以适当放大
- **垂直放大时必须在图下注明**（如"垂直比例尺放大2倍"）
- 比例尺的选择原则：能清楚表现地质结构，但不过分夸张

**3. 绘制地形线**
- 从地形图上读取剖面线的高程变化
- 在纸上画出地形起伏
- 水平距离从地形图上量取

**4. 填绘地质内容**
- 按野外实际观察的地层顺序，从老到新（从下到上）填入
- 标注各地层单位的岩性花纹（用 FGDC 标准或标准的花纹）
- 画出地层分界线
- 标注断层、褶皱等构造

### 岩性花纹要求

| 岩性 | 表现要点 |
|------|---------|
| 软岩层（页岩/泥岩/煤层） | 表现细微纹理特点，用细密线条 |
| 硬岩层（砂岩/石英岩/玄武岩） | 表现裂隙发育，节理面 |
| 砂泥岩互层 | 区分粗细，粗粒用粗点，细粒用细点 |
| 多成分混杂 | 先画主体，再叠加次要成分花纹 |
| 碳酸盐岩 | 用砖块状花纹，加溶蚀孔洞符号 |

### 地层接触关系画法
- **整合（平行不整合）**：画成波状起伏的线，示侵蚀间断
- **整合**：平滑曲线
- **角度不整合**：上覆地层截切下伏地层的层理
- **标志层**：用特殊花纹标注，作为追索构造形态的依据

### 必须标注的内容（检查清单）
- [ ] 图名（含路线号、剖面名称）
- [ ] 比例尺（数字比例尺 + 线段比例尺）
- [ ] 图例（按地层从老到新排列，用标准地层代号）
- [ ] 指北针（或剖面方向箭头）
- [ ] 地层代号（如 P2β、T1f、T1j）
- [ ] 产状符号（标注代表性产状，字头朝北）
- [ ] 断层符号及编号
- [ ] 各观察点的位置及编号
- [ ] 地名/地物标注
- [ ] 图切好→全部用黑墨水清绘

## 二、路线地质示意图

- 比例尺：1:5000 ~ 1:10000
- 在野外随路线推进同步绘制
- 标注内容：
  - 观察点（D编号）
  - 产状（倾向/倾角）
  - 标本/化石采集点
  - 岩性花纹
  - 断层线、地层界线
  - 前方标注：地名、河流方向
- 断层线/地层线应圆滑，产状符号准确
- 路线方向标志箭头

### 平面图上符号规范
- 观察点/泉/采样点：圆圈，直径 1.5~2mm
- 产状数字：字高 2~3mm
- 地质界线：连续、圆滑
- 断层线：粗红线（在正式图上）
- V 字形法则：地层界线过沟谷时向沟头弯曲

## 三、地质素描

### 露头素描 vs 构造素描

| | 露头素描 | 构造素描 |
|------|---------|---------|
| 目的 | 记录岩性、层理、沉积构造 | 记录构造形态和空间关系 |
| 重点 | 岩层颜色、厚度变化、沉积特征 | 褶皱形态、断层关系、节理系统 |
| 画法 | 写实为主，标注岩性符号 | 线条为主，突出构造要素 |

### 素描基本要求
1. **选定范围**：明确画什么——从路边到山顶？水平距离多少？
2. **比例适当**：关键地质体不能太小看不清
3. **标注指向**：图中关键要素用引线标注名称
4. **简化适当**：不是照相似的，无关植被、浮土可省略
5. **重点突出**：构造素描中，岩层界线比岩性花纹更重要

### 素描检查清单
- [ ] 图名
- [ ] 比例尺
- [ ] 方向（指北或剖面方向）
- [ ] 关键地质体标注（岩性、地层代号、产状）
- [ ] 引线清晰不交叉
- [ ] 图中不标注的颜色/花纹含义在图外说明

## 三、综合地层柱状图

> 通用图件规范

柱状图是按时间顺序综合表示地层序列的标准图件。

**绘制步骤**：
1. 整理实测剖面数据，计算各层厚度
2. 根据化石/同位素确定各层时代，建立地层序列
3. 确定各层岩性花纹（参见 [symbols.md](../references/symbols.md)）
4. 按厚度比例绘制柱体（可用对数比例表示薄层）
5. 标注：地层单位名称、代号、厚度、岩性花纹、化石、接触关系
6. 右侧标注沉积环境/海平面变化曲线（可选）

**柱状图必须包含**：
- 地层单位（组/段）的名称和代号
- 各单位的厚度（按比例尺）
- 岩性花纹（标准图例）
- 地层接触关系（整合/平行不整合/角度不整合）
- 化石层位
- 岩浆岩（如有）

## 四、构造纲要图

> 通用图件规范

构造纲要图是用规定符号概括表示区域构造格局的图件。

**必须标注的构造要素**：

| 符号 | 含义 |
|------|------|
| 背斜轴线 + 箭头 | 背斜（标注枢纽倾伏方向） |
| 向斜轴线 + 箭头 | 向斜（标注枢纽倾伏方向） |
| 粗实线 + 三角 | 逆断层（三角指向上盘） |
| 粗实线 + 短齿 | 正断层（齿指向下盘） |
| 半箭头 | 平移断层 |
| 封闭曲线 | 飞来峰 |
| 窗口形曲线 | 构造窗 |
| 波浪线 | 角度不整合 |
| 虚线 | 平行不整合 |
| ┴ 符号 | 产状（标注倾向/倾角） |

**绘制原则**：
- 先标观察点/采样点/工程位置
- 再画地质界线
- 最后填构造符号
- 断层线圆滑，产状符号准确
- 所有构造要素标注编号和名称

## 五、常见坑
- 剖面方向不垂直于岩层走向→视倾角错误
- 垂直放大比例没标注→读图者误判
- 图例不完整→别人看不懂
- 地层代号不规范→扣分
- 产状符号字头方向不统一
- 素描图过于潦草→无法辨认关键地质要素
