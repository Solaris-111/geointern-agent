# 野簿预稿模板

> 使用说明：复制此模板，将 `___` 替换为实际内容。`[ ]` 内的内容根据实际情况保留或删除。
> 野簿预稿模板（通用格式）

---

```
YYYY年M月D日  星期X  天气：___
地点：北京市房山区周口店

路线：[起点] → [途经点1] → [途经点2] → [终点]
路线号：LXX

任务：
① [动词开头，从实习指定原文抄录]
② [动词开头，从实习指定原文抄录]
③ [动词开头，从实习指定原文抄录]
```

> ⚠️ 路线名称和任务必须从实习路线要求原文逐条抄录。往年野簿有笔误时以路线要求为准。
