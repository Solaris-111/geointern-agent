# 变质岩野外鉴定

> 通用地质知识（可参考 OpenGeology 变质岩章节）+ 周口店实习实例
> 峨眉山变质岩极少，周口店三种变质类型齐全

---

## 第一步：判断变质岩大类

```
拿到一块变质岩
      │
      ▼
┌────────────────────┐
│ 变质作用类型？       │
│ 看产状+分布范围+构造 │
└────────┬───────────┘
         │
    ┌────┼────────┬────────┐
    ▼    ▼        ▼        ▼
  大面积   岩体周边   断裂带内   断层附近
  区域变质  接触变质  动力变质   碎裂变质
```

| 类型 | 分布范围 | 典型构造 | 周口店实例 |
|------|---------|---------|----------|
| 区域变质 | 数km²以上 | 片理/片麻理 | 官地杂岩、下马岭组片岩 |
| 热接触变质 | 岩体周边数百米 | 角岩结构、斑点状 | 房山岩体外围角岩带 |
| 动力变质 | 断裂带内 | 糜棱面理、碎斑 | 韧性剪切带糜棱岩 |

---

## 变质岩结构类型

| 结构 | 特征 | 说明 |
|------|------|------|
| 变晶结构 | 变质结晶形成，矿物自形 | 按粒度分粗/中/细粒变晶 |
| 变余结构 | 残留原岩结构 | 如变余砂状、变余泥状结构 |
| 交代结构 | 交代作用形成 | 矿物被置换 |
| 碎裂结构 | 脆性变形，颗粒破碎 | 动力变质岩特征 |
| 糜棱结构 | 韧性变形，细粒化 + 定向 | 糜棱岩特征 |

## 第二步：区域变质岩鉴定

```
板状构造 → 板岩（极低级）
千枚状构造 → 千枚岩（低级，丝绢光泽）
片状构造 → 片岩（中级，片状矿物>50%）
片麻状构造 → 片麻岩（中高级，长石+石英条带）
```

### 周口店区域变质岩序列

**官地杂岩（ArG）** — 太古宇基底
- 黑云斜长片麻岩：斜长石55% + 石英30% + 黑云母15%
- 角闪斜长片麻岩、混合片麻岩
- 斜长角闪岩：角闪石+斜长石，柱状变晶结构
- 后期强动力变质叠加 → 糜棱岩化

**下马岭组（Qbx）变质分带**（房山岩体热叠加）
```
石榴子石云母片岩
    ↓ 变质程度降低
石榴红柱石云母片岩
    ↓
红柱石云母片岩
    ↓
炭质板岩 → 变质粉砂岩 → 炭质板岩 → 板岩
```

### 板岩亚类（周口店实例）

| 类型 | 产地 | 特征 |
|------|------|------|
| 含黄铁矿压力影板岩 | 太平山南坡本溪组 | 黄铁矿旋转变形，石英拖尾 |
| 钙质板岩 | 黄院东山梁景儿峪组 | 灰色薄层，变余泥质结构 |
| 含孔雀石板岩 | 黄院东山梁徐庄组 | 灰绿色，孔雀石薄膜沿板理 |
| 炭质板岩 | 山西组 | 黑色，炭质含量高→煤线 |
| 千枚状板岩 | 下马岭组、馒头组 | 弱硅化，过渡类型 |

## 第三步：热接触变质岩鉴定

```
岩体周边 → 看距离岩体远近
    │
    ├── 近岩体（<100m）：高温矿物组合
    │       红柱石角岩、矽线石角岩、辉石角岩
    │
    ├── 中距离（100-500m）：中温矿物组合  
    │       角岩、斑点板岩、堇青石角岩
    │
    └── 远距离（>500m）：低温矿物组合
            斑点板岩、弱角岩化
```

### 周口店接触变质带（房山岩体外围）

| 距离 | 岩石类型 | 特征矿物 | 特征 |
|------|---------|---------|------|
| 近（<450m） | 堇青石角岩 | 堇青石（菊花石） | 斑晶(2-3)×(7-8)mm，菊花状集合体 |
| 中 | 红柱石角岩 | 红柱石 | 柱状斑晶，含Fe³⁺致色多变 |
| 中 | 硬绿泥石角岩 | 硬绿泥石 | 暗灰-黑灰，风化褐红，70%含量 |
| 远 | 斑点板岩 | — | 接触变质最外带 |

### 角岩鉴定要点
- **堇青石角岩**：堇青石呈菊花状集合体，直径2-10mm
- **红柱石角岩**：红柱石斑状变晶，含碳质包体呈十字形（空晶石）
- **硬绿泥石角岩**：新鲜面绿色，风化褐红色，无定向排列

### 大理岩系列（周口店接触变质）

| 类型 | 产地 | 特征矿物 |
|------|------|---------|
| 透闪石大理岩 | 铁岭组 | 白色纤维状透闪石条带 |
| 硅灰石大理岩 | 雾迷山组、铁岭组 | 硅灰石白色板状，1.5×5mm |
| 含镁橄榄石大理岩 | 铁岭组 | 橄榄石8-15%，暗色粒状 |

**温压条件判断**：
- 透闪石出现 → 400-430°C
- 硅灰石出现 → 接触变质高级
- 镁橄榄石出现 → 高温（硅质白云岩变质）

### 片岩系列（接触变质叠加区域变质）

下马岭组（Qbx）中出现多种特征变质矿物：
- 石榴子石云母片岩 → 中级变质
- 红柱石云母片岩 → 低压高温
- 矽线石云母片岩 → 高级变质

## 第四步：动力变质岩鉴定

```
断裂带内 → 看变形程度
    │
    ├── 脆性变形：碎裂岩系列
    │       断层角砾岩 → 碎裂岩 → 碎斑岩
    │
    └── 韧性变形：糜棱岩系列
            初糜棱岩 → 糜棱岩 → 超糜棱岩
```

### 碎裂岩系列

| 类型 | 特征 | 基质比例 |
|------|------|---------|
| 断层角砾岩 | 棱角状碎块，被胶结 | <30% |
| 碎裂岩 | 碎斑+碎基，裂隙发育 | 30-50% |
| 碎斑岩 | 残斑在细粒基质中 | 50-90% |

### 糜棱岩系列

| 类型 | 特征 | 基质比例 |
|------|------|---------|
| 初糜棱岩 | 残斑多，定向弱 | 10-50% |
| 糜棱岩 | 残斑少，透入性面理 | 50-90% |
| 超糜棱岩 | 几乎全基质 | >90% |

### S-C组构（韧性剪切带关键标志）

```
S面理 = 挤压面理（早期，平行应变椭球XY面）
C面理 = 剪切面理（稍晚，平行剪切带边界）

S与C的夹角 → 剪切方向：
  S面理被C面理切割 → C面理代表剪切方向
  锐角指向 → 对盘运动方向
```

### 糜棱岩中的指向构造

| 构造 | 指示 |
|------|------|
| S-C组构 | C面理方向=剪切方向 |
| 旋转残斑（σ型、δ型） | 残斑拖尾指向对盘运动方向 |
| 云母鱼 | 云母被剪切拉断 |
| 书斜构造（多米诺） | 脆性矿物斜列方向 |
| 压力影 | 刚性矿物两侧的纤维状低压沉淀 |
| 石英C轴组构 | 统计方法确定剪切方向 |

## 变质相快速判断

| 变质相 | 温度 | 压力 | 标志矿物组合 | 周口店实例 |
|--------|------|------|-------------|----------|
| 绿片岩相 | 300-500°C | 低-中压 | 绿泥石+绢云母+石英 | 板岩、千枚岩 |
| 角闪岩相 | 500-700°C | 中压 | 角闪石+斜长石 | 斜长角闪岩 |
| 角岩相 | 400-600°C | 极低压 | 红柱石+堇青石 | 房山岩体外围角岩 |
| 麻粒岩相 | >700°C | 中-高压 | 辉石+斜长石（无角闪石） | 官地杂岩局部 |

## 常见坑
- 把片麻岩当成花岗岩 → 片麻岩有黑白条带（片麻理），花岗岩矿物随机排列
- 把接触变质当成区域变质 → 看分布范围：接触变质只在岩体周边
- 分不清角岩和板岩 → 角岩无片理、断口瓷质；板岩有板理
- 忘了记录变质带序列 → 从远到近逐个采样，记录矿物出现/消失
