## 颜色分类（色率法）

| 色率 | 分类 | 典型岩石 |
|------|------|---------|
| >90% | 超基性岩 | 橄榄岩 |
| 40-90% | 基性岩 | 玄武岩、辉长岩 |
| 15-40% | 中性岩 | 安山岩、闪长岩 |
| <15% | 酸性岩 | 流纹岩、花岗岩 |

色率 = 暗色矿物（橄榄石、辉石、角闪石、黑云母）所占面积百分比

## 结构分类

| 结构 | 特征 | 形成环境 |
|------|------|---------|
| 全晶质粗粒（>5mm） | 矿物全结晶，肉眼可辨 | 深成岩（地下深处缓慢冷却） |
| 全晶质中粒（1-5mm） | 矿物全结晶，放大镜可辨 | 深成岩 |
| 全晶质细粒（<1mm） | 矿物全结晶，肉眼难辨 | 浅成岩 |
| 半晶质/斑状 | 大晶体（斑晶）+隐晶质基质 | 浅成岩或喷出岩 |
| 玻璃质 | 无结晶，玻璃光泽 | 喷出岩（急速冷却） |

## 构造分类

| 构造 | 特征 | 指示 |
|------|------|------|
| 块状构造 | 矿物均匀分布，无定向 | 深成岩 |
| 气孔构造 | 圆形/椭圆形孔洞 | 喷出岩（玄武岩标志） |
| 杏仁构造 | 气孔被后期矿物充填 | 喷出岩（玄武岩） |
| 流纹构造 | 不同颜色条带/条纹 | 酸性喷出岩（流纹岩） |
| 柱状节理 | 冷却收缩形成六方柱体 | 基性喷出岩（玄武岩） |

## 岩浆岩产状（岩体形态）

| 产状 | 形态 | 侵入/喷出 |
|------|------|----------|
| 岩基 | 巨大不规则体（>100km²） | 深成侵入 |
| 岩株 | 较小不规则体（<100km²） | 深成侵入 |
| 岩墙（岩脉） | 板状，切穿围岩层理 | 浅成侵入 |
| 岩床 | 板状，顺层理侵入 | 浅成侵入 |
| 岩盖 | 蘑菇状，上凸下平 | 浅成侵入 |
| 岩被 | 大面积层状覆盖 | 喷出 |
| 熔岩流 | 沿地形流动的岩流 | 喷出 |

## 主要造岩矿物识别

| 矿物 | 颜色 | 形态 | 光泽 | 解理 | 特征 |
|------|------|------|------|------|------|
| 石英 | 无色 | 粒状 | 油脂 | 无 | 硬度>小刀，断口贝壳状 |
| 钾长石 | 肉红色/白色 | 板状 | 玻璃 | 两组近90° | 易风化呈白色土状 |
| 斜长石 | 白色/灰白 | 长条状 | 玻璃 | 两组近90° | 可见聚片双晶纹 |
| 黑云母 | 黑色/褐黑 | 片状 | 珍珠 | 一组极完全 | 小刀可剥成薄片，有弹性 |
| 角闪石 | 墨绿/黑绿 | 长柱状 | 玻璃 | 两组交角124°/56° | 硬度>小刀 |
| 辉石 | 墨绿/黑 | 短柱状 | 玻璃 | 两组近90° | 硬度>小刀 |
| 橄榄石 | 橄榄绿 | 粒状 | 玻璃 | 无 | 易蚀变为蛇纹石 |

## 岩浆岩野外记录格式

按以下顺序描述：
1. **岩石名称** — 颜色 + 构造 + 结构 + 主要矿物 + 基本名称
2. **颜色** — 新鲜面色 + 风化色
3. **结构 + 构造** — 特别是结晶程度、颗粒大小和自形程度
4. **矿物成分及含量** — 主要矿物（>10%）+ 次要矿物（5-10%）+ 副矿物（<5%）
5. **次生蚀变** — 蚀变类型和强度
6. **产状** — 岩体形态、与围岩接触关系
7. **标本编号**

## 峨眉山本地实例

### 峨眉山玄武岩（P2β）
- **时代**：晚二叠世
- **分布**：路线一（清音电站→龙门硐电站）、路线三（洪椿坪附近）
- **颜色**：深灰色→暗绿色（色率 60-80，基性）
- **结构**：隐晶质基质 + 斑晶（斜长石、辉石）
- **构造**：气孔构造 + 杏仁状充填（方解石、玉髓）+ 柱状节理
- **产状**：裂隙式喷发，岩被状产出；下伏茅口组（P2m）平行不整合接触，上覆宣威组（P3x）平行不整合接触
- **厚度**：约 258m（龙门硐电站剖面）
- **常见坑**：**别把杏仁状充填当斑晶**——杏仁体是后来填进去的，斑晶是跟岩浆一起结晶的

### 峨眉山花岗岩
- **时代**：待定
- **分布**：路线三（洪椿坪附近）、张沟
- **颜色**：灰白→浅肉红色（色率 <15，酸性）
- **结构**：中-粗粒全晶质
- **主要矿物**：石英（25%）、钾长石（50%）、斜长石（20%）
- **次要矿物**：黑云母、角闪石（10%）

### 峨眉山辉绿岩
- **分布**：路线一、张沟、余坪等地
- **特征**：浅成侵入岩，具辉绿结构
- **产状**：岩脉/岩墙，侵入于玄武岩中
