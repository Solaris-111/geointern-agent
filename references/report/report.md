# 实习报告写作

> 实习报告写作规范（通用）

---

## 核心原则

**报告的数据来源是野簿，不是记忆。** 写报告前先把野簿翻一遍，把每个观察点的GPS坐标、产状数据、素描图编号整理出来——这些才是报告的骨架。

---

## 报告结构

一份完整的实习报告由四部分组成：

```
封面 → 目录 → 正文 → 参考文献
```

### 封面
- 标题：`XX地区地质认识实习报告`
- 学校/学院
- 姓名、学号
- 指导教师
- 实习日期
- 格式参考：封面标准格式

### 目录
- 列出全部章节标题及对应页码
- 多级标题缩进排列
- 格式参考：目录标准格式

### 正文（三段式）

#### 一、前言

内容包括：
- 实习的基本情况（时间、地点、人员组成）
- 实习区的自然地理和交通状况
- 实习区地质研究历史（分阶段简述）
- 实习的目的、任务、内容及要求
- **完成工作量统计表**（观察点数、路线长度、实测剖面、素描图数、产状数等——数据来自野簿统计）

#### 二、各论（主体部分）

按以下顺序分章节写，**每章先概述再详述**：

**1. 地层**（从老到新排列）

**每个地层组的五要素——缺一不可：**

| 要素 | 内容 | 示例 |
|------|------|------|
| 岩性 | 颜色+构造+结构+成分+岩石全名 | `浅灰色中厚层状中粗粒变质石英砂岩` |
| 化石 | 拉丁学名全称 | *Fusulina* sp.（纺锤蜓） |
| 厚度 | 具体数字 | 约62.5m |
| 接触关系 | 类型+证据 | 平行不整合，发育约50cm褐铁矿古风化壳 |
| 图号 | 素描图/剖面图引用 | （图2-1）、（图2-6） |

- 不准只说"砂岩"，必须写"中粒长石石英砂岩"
- 实测剖面必须**逐层描述**，不能只写总厚度
- 每个组的描述中引用野簿素描图号——证明你真的在野外画了

**实测剖面逐层描述格式（参考周口店太平山南坡本溪组）：**
```
上覆地层：太原组（C₂t）灰绿色中厚层细粒粉砂岩 …… 9m
————————— 整合接触 —————————

本溪组（C₂b）：厚62.5m

⑦ 深灰色压力影板岩 ……………………………………… 11m
⑥ 灰色含生物碎屑唐山灰岩 ……………………………… 2m
⑤ 黄色变余砂状结构板状构造板岩 ……………………… 12.5m
④ 灰色斑状变晶结构块状构造红柱石角岩 ……………… 5.5m
③ 黑绿色斑状变晶结构块状构造硬绿泥石角岩 ………… 2.5m
② 白灰色斑状长英质结构块状构造红柱石角岩 ………… 6m

————— 平行不整合 —————

下伏地层：马家沟组（Om）
① 灰色细晶结构岩溶角砾岩 ………………………………… 6m
```

**2. 沉积环境分析**（周口店报告必写）

对每个时代的地层进行沉积相推断，从岩性和原生沉积构造出发，不做空中楼阁式的推测。格式：`地层 → 岩性特征 → 沉积构造 → 沉积环境`。

**3. 岩浆岩**

- 沉积岩 → 岩浆岩 → 变质岩（按出露面积和重要性排序）
- 沉积岩：颜色、粒度、成分、沉积构造、层面特征
- 岩浆岩：颜色、结构、构造、**矿物成分及百分含量**、产状、与围岩接触关系
- 变质岩：构造类型、矿物组合、变质程度
- 岩浆岩必须拆分到**单元/相带**级别——不能说"房山岩体是花岗闪长岩"就完了
- 每个亚类/单元/相带标注产地和层位

**4. 变质岩**

必须细分亚类（不能只说"板岩"，要分：含黄铁矿压扁板岩/钙质板岩/含孔雀石薄层板岩/炭质板岩/千枚状板岩），每个亚类写产地+层位+特征变质矿物。

**5. 构造**

- 倾斜岩层构造 → 褶皱 → 节理 → 断层 → 韧性剪切带 → 推覆构造
- 褶皱：核部地层+时代、两翼地层+时代、枢纽产状、轴面产状、转折端形态、规模
- 断层：断层面产状、两盘地层、断层证据（≥2项）、断层性质（正/逆/平移）、破碎带宽度
- **构造演化序列（D₁-D₉）是拉开差距的关键**——不能只列构造名称
- 构造章节至少引用5张以上野簿素描图

**6. 地质发展史**

按**基底形成→盖层形成→盖层活化→新构造**四阶段写，每个阶段标注代表性构造运动和地层记录。

**7. 经济地质**（周口店必写，峨眉山不写）

矿产、工程地质、水文地质、地貌、旅游地质、灾害地质。或按专题写成小论文形式替代。

**小论文替代方案：**
可选择一个专题写成短论文，如：
- "峨眉山玄武岩的野外鉴定"
- "飞仙关组沉积环境分析"
- "河流阶地的形成过程及研究意义"
- "峨眉山花岗岩的地质特征"
- "房山岩体岩浆混合作用的地质证据"

#### 三、结论（认识与成果）

按五个方向分别总结（不是泛泛的"提高了认识"）：
1. 地层方面——具体认识了哪些组、什么特征
2. 岩浆岩方面——具体观察了什么岩体、什么特征
3. 变质岩方面——具体识别了哪些类型、什么产地
4. 构造方面——具体掌握了哪些构造现象的判读
5. 经济地质方面（周口店）/野外技能方面

**结束语：** 有人（指导老师姓名）、有事（具体经历）、有情感（真实体会），不要模板化。

### 参考文献

格式示例：
```
[1] 王根厚, 敖月平, 王景胜, 刘文灿主编. 周口店地区地质实习指导书. 中国地质大学（北京）出版社, 2006.
[2] 肖渊甫, 郑荣才, 邓江红等. 岩石学简明教程[M]. 北京: 地质出版社, 2009.
[3] 宋鸿林. 北京房山变质核杂岩的基本特征及其成因探讨. 1996.
```

## 室内整理流程（野外结束后）

### 1. 路线小结
每条路线观察结束后写小结：
- 路线基本情况（长度、点数、标本数、素描数）
- 主要成果
- 存在问题
- 思考题+个人回答
- 自我评估

### 2. 标本登记
- 逐一核对标本、样品、照片编号
- 标本登记表（编号+名称+采集地点+层位+日期）
- 照片登记表（编号+拍摄内容+地点+方向+日期）

### 3. 图件整理

**地形图清绘：**
- 观察点/泉/采样点：圆圈直径 1.5-2mm
- 产状数字：字高 2-3mm，字头朝北
- 地质界线：圆滑、连续
- 断层线：粗线，标运动方向
- 地层代号：标准字体，大小统一

**野簿图件清绘：**
- 信手剖面图、构造素描图、路线平面图 → 着墨清绘
- 加图名、比例尺、图例、方向标
- 标注观察点号、产状、地层代号

### 4. 着墨
- 所有铅笔标注 → 黑墨水清绘
- 批注用红墨水
- 禁止涂改

## 常见扣分项

| 严重度 | 问题 | 怎么避免 |
|--------|------|---------|
| **致命** | 报告中无野簿数据支撑 | 写报告前翻野簿，产状/坐标/素描图号必须引用 |
| **致命** | 实测剖面只给总厚度 | 逐层描述，每层厚度+岩性 |
| **致命** | 图没标比例尺 | 每张图检查：图名+比例尺+指北针+图例 |
| **严重** | 地层描述缺要素 | 岩性+化石+厚度+接触关系+图号，五要素缺一不可 |
| **严重** | 指北针没画 | 信手剖面标剖面方向，平面图标指北 |
| **严重** | 图例不完整 | 所有图中出现的地层代号都要入图例 |
| **严重** | 地层代号不规范 | 用标准代号：P₂β不是"玄武岩" |
| **严重** | 产状数据没标在图上 | 剖面图和平面图都要标产状 |
| **严重** | 岩性描述太笼统 | 不能说"砂岩"，必须说"灰白色中粒长石石英砂岩" |
| **中等** | 忘了路线小结 | 每天野外回来当天写 |
| **中等** | 标本编号混乱 | 野外当场编号，别回来再补 |
| **中等** | 参考文献格式不对 | 按标准格式：作者. 题名[M/J]. 出版地: 出版社, 年份. |
| **轻微** | 结论泛泛而谈 | 按学科分点总结具体收获 |

## 峨眉山 vs 周口店报告差异

| 方面 | 峨眉山 | 周口店 |
|------|--------|--------|
| 正文字数 | 2000字以上（不含图件） | 约10000字（含图件说明） |
| 报告题目 | 《峨眉山地区地质认识实习报告》 | 《北京市房山区周口店地区地质认识报告》 |
| 章节 | 地层→岩浆岩→构造→地质发展史 | 地层→沉积环境→岩浆岩→变质岩→构造→地质发展史→经济地质 |
| 沉积环境 | 选写 | **必写**（专节） |
| 变质岩 | 选写（峨眉山不发育） | **必写**（区域+接触+动力，分亚类） |
| 经济地质 | 不写 | **必写**（矿产+旅游+灾害+工程） |
| 构造 | 断层+节理+褶皱 | 褶皱+断层+韧性剪切带+推覆构造+构造演化序列 |
| 素描图引用 | 建议 | **大量引用**（证明野外工作量） |
| 工作方法 | 选写 | **必写**（填图流程、"V"字形法则等） |

## 时间线建议

| 阶段 | 时间 | 任务 |
|------|------|------|
| 野外期间 | 每天 | 当天写路线小结，整理野簿，登记标本照片 |
| 野外结束后1-2天 | 室内 | 清绘野簿图件，整理全部观察点数据表 |
| 第3-5天 | 室内 | 写正文各章节（按地层→岩浆岩→变质岩→构造→地质发展史→经济地质顺序） |
| 第6-7天 | 室内 | 绘制正式图件（柱状图、赤平投影、剖面图、构造纲要图） |
| 最后2天 | 室内 | 全文通读修改，检查图件与正文引用对应，打印装订 |
