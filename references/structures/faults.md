## 断层证据清单

### 1. 擦痕与阶步（最直接证据）
- **擦痕**：断层面上的平行细沟，指示两盘相对滑动方向
- **阶步**：擦痕末端的微小陡坎
- **判断方向**：手摸断层面，**顺光滑方向为对盘运动方向**；阶步陡坎面朝对盘运动方向

### 2. 断层角砾岩
- 断层带内的岩石碎块被压碎后重新胶结
- 角砾成分为断层两侧岩石
- 角砾呈棱角状（区别于沉积砾岩的磨圆）

### 3. 牵引褶皱
- 断层两盘的岩层在断层面附近发生弯曲（拖曳）
- 弯曲方向指示对盘运动方向

### 4. 地层重复或缺失
- 正常层序中，某段地层在横穿断层时重复出现→逆断层
- 正常层序中，某段地层缺失→正断层
- **需先确认地层正常层序（未倒转）**

### 5. 其他辅助证据
- **断层面**：光滑的镜面（摩擦镜面）
- **硅化/矿化**：断层面附近硅化或矿化
- **泉水线**：沿断层线分布的泉水
- **地貌标志**：断层崖、断层三角面、线性沟谷

## 断层几何要素

| 要素 | 定义 |
|------|------|
| 断层面 | 岩层破裂后沿之滑动的面，测其产状（倾向/倾角） |
| 断层线 | 断层面与地面的交线 |
| 上盘 | 断层面之上的岩块 |
| 下盘 | 断层面之下的岩块 |
| 滑距 | 断层面上实际错开的距离（沿断层面量取） |
| 断距 | 被错开地层在铅直/水平方向的视错距 |

> 上盘/下盘：站在断层面朝下坡方向，脚下的盘为下盘。

## 断层类型判断

| 类型 | 力学性质 | 上盘运动 | 证据特征 |
|------|---------|---------|---------|
| **正断层** | 拉张 | 上盘下降 | 地层缺失、张性角砾岩 |
| **逆断层** | 挤压 | 上盘上升 | 地层重复、挤压破碎带、牵引褶皱 |
| **平移断层** | 剪切 | 水平滑动 | 擦痕水平、地貌位错 |
| **平移-正/逆断层** | 复合 | 斜向滑动 | 擦痕倾斜，兼有垂向和水平分量 |

## 断层野外记录格式

1. **断层名称**（位置命名：如"回龙山断层"）
2. **断层的位置**及构造部位
3. **断层面产状**（倾向/倾角）
4. **两盘地层单位及岩性**
   - 注明上盘：`P2β（上盘）`
   - 注明下盘：`T1f（下盘）`
5. **断层证据**（擦痕/阶步/角砾岩/牵引褶皱，至少列两项）
6. **断层性质**（正/逆/平移）
7. **断层规模**
   - 破碎带宽度
   - 断距（地层断距/垂直断距/水平断距）
8. **断层素描图**（标注运动方向）
9. **断层岩/构造岩标本**

## 断距三要素

| 参数 | 定义 | 测量方式 |
|------|------|---------|
| 地层断距 | 同一层被错开的垂直距离（沿地层法线方向） | 从剖面图量取 |
| 垂直断距 | 上下盘同一层的海拔差 | 从地形图上读取 |
| 水平断距 | 上下盘同一层在水平方向上的错开距离 | 从平面图上量取 |

## 常见坑
- 看到一个擦痕就下结论 → 必须有至少两项证据
- 不判断上盘下盘 → 分不清正逆
- 把沉积砾岩当成断层角砾岩 → 断层角砾岩棱角状、成分与两盘岩性一致
- 地层倒转时用"地层缺失/重复"判断正逆 → 倒转地层判断结果相反
- 不量断层面产状 → 最有价值的数据没记
- 素描不标运动方向 → 图白画了
