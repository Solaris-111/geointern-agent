## 一、韧性剪切带鉴定

### 决策树

```
疑似韧性剪切带
      │
      ▼
┌─────────────────────┐
│ 1. 看变形机制        │
│ 脆性？韧性？          │
└────────┬────────────┘
         │
    ┌────┴────┐
    ▼         ▼
 碎裂/角砾   矿物拉长、定向
 脆性断裂    透入性面理
    │         │
    ▼         ▼
  断层带     韧性剪切带 → 继续
              │
              ▼
┌─────────────────────┐
│ 2. 找标志构造        │
│ 至少中2项可确认      │
└────────┬────────────┘
         │
    ┌────┼────┬────┬────┐
    ▼    ▼    ▼    ▼    ▼
  S-C   旋转  鞘褶  糜棱  拉伸
  组构  残斑  皱   面理  线理
         │
         ▼
┌─────────────────────┐
│ 3. 判断剪切方向      │
│ C面理∥剪切带边界     │
│ S-C锐角→对盘方向     │
└────────┬────────────┘
         │
         ▼
      确定剪切指向！
```

### S-C组构（最重要的识别标志）

```
S面理 (Schistosity)
  = 早期挤压面理
  = 矿物定向排列面
  = 平行应变椭球XY面

C面理 (Cisaillement)  
  = 晚期剪切面理
  = 平行剪切带边界
  = 切割S面理

S与C的锐角夹角 → 指向对盘运动方向
```

**野外识别**：
1. 先找C面理（平行的、间距较大的剪切面）
2. 再找C面理之间的S面理（倾斜的、由矿物定向构成）
3. S面理弯曲汇入C面理 → 确认S-C组构
4. S-C锐角方向 = 对盘剪切方向

### 鞘褶皱（韧性剪切带特有）

| 特征 | 描述 |
|------|------|
| 形态 | 垂直X轴剖面呈椭圆形/近圆形封闭状 |
| 成因 | 剪切过程中褶皱枢纽旋转至平行拉伸线理方向 |
| 识别 | 在Y-Z截面上呈封闭椭圆形，X-Z截面上呈拉长的鞘状 |
| 周口店位置 | 孤山口火车站北侧多处出露 |

### 糜棱面理

| 特征 | 描述 |
|------|------|
| 定义 | 韧性剪切带中透入性的矿物定向排列面 |
| 成因 | 矿物在剪切作用下重结晶+定向 |
| 与其他面理区别 | 糜棱面理透入性更强，颗粒更细（<0.5mm） |

### 拉伸线理

| 类型 | 特征 | 指示 |
|------|------|------|
| 矿物拉伸线理 | 石英、云母、长石定向排列 | A型线理，指示拉伸方向 |
| 窗棂构造 | 走向垂直于挤压方向 | 大型B型线理 |

### 石香肠构造（Boudinage）

- 强硬层在韧性基质中被拉伸断裂
- 断裂面垂直拉伸方向
- 肠状节段之间被基质充填
- 指示：拉伸方向平行于香肠排列方向

### 脆性断层 vs 韧性剪切带

| 特征 | 脆性断层 | 韧性剪切带 |
|------|---------|-----------|
| 变形机制 | 破裂 + 摩擦滑动 | 晶体塑性变形 + 重结晶 |
| 标志构造 | 角砾岩、擦痕、阶步 | S-C组构、糜棱面理、鞘褶皱 |
| 变形带宽度 | 窄（几 cm～几 m） | 宽（几 m～几 km） |
| 岩石 | 碎裂岩系列 | 糜棱岩系列 |
| 形成深度 | 浅部（<10km） | 深部（>10-15km） |

## 二、逆冲推覆构造鉴定

### 决策树

```
疑似推覆构造
      │
      ▼
┌─────────────────────┐
│ 1. 找地层异常        │
│ 老地层盖在新地层之上？ │
└────────┬────────────┘
         │
    是 → 可能是逆冲推覆
    否 → 看褶皱倒转翼
         │
         ▼
┌─────────────────────┐
│ 2. 找断层证据        │
│ 断层面+角砾岩+擦痕   │
└────────┬────────────┘
         │
    ┌────┼────┐
    ▼    ▼    ▼
  飞来峰  构造窗  叠瓦状
         │
         ▼
┌─────────────────────┐
│ 3. 判断类型          │
│ 单条逆冲？叠瓦状？    │
└────────┬────────────┘
         │
    ┌────┴────┐
    ▼         ▼
  单条逆断层   叠瓦状逆冲系
  老→新直接   多条依次叠置
  覆盖        │
              ▼
         双重逆冲构造
         (duplex)
```

### 关键术语

| 术语 | 定义 | 周口店实例 |
|------|------|----------|
| **飞来峰** | 逆冲推覆体被侵蚀后残留的孤立老地层块体 | 房山变质核杂岩周边 |
| **构造窗** | 逆冲面以下的新地层在侵蚀窗口中出露 | 官地构造窗 |
| **叠瓦状构造** | 多条逆断层依次叠置，呈瓦片状 | 黄山店褶皱冲断带 |
| **双重逆冲构造** | 顶板逆冲断层+底板逆冲断层，夹持叠瓦状断片 | 孤山口 |

### 周口店逆冲推覆序列

```
D1: 同沉积构造阶段（SE向剪切）
    低角度顺层韧性剪切带

D2: 逆冲推覆阶段（SSW→NNE逆冲）
    孤山口褶皱冲断（SSW向）
    黄山店褶皱冲断（NNW向）
    
D3: 164背斜、太平山向斜形成（NW向挤压）

D4: NE-NNE向隐伏断裂和褶皱（NW向挤压）

D5: 基底进一步隆升

D6: 南大寨冲断层（NEE向脆性推覆）

D7: 近EW向断裂+岩浆侵入（131-128Ma）

D8: 房山岩体西北缘韧性剪切带（125-130Ma）

D9: 燕山期SE向伸展，高角度正断层系
```

### 识别标志

| 标志 | 说明 |
|------|------|
| 老地层在新地层之上 | 逆冲最直接的证据 |
| 地层重复/加厚 | 同一套地层钻探中反复出现 |
| 地层缺失/减薄 | 逆冲面削截部分地层 |
| 倒转褶皱 | 逆冲推覆前端常见 |
| 脆性强的岩层被拉断（石香肠化） | 强硬层在韧性基质中不连续 |
| S₁面理横向置换S₀ | 顺层拖卧褶皱的轴面面理替代原始层面 |

## 三、野外记录要点

### 韧性剪切带记录清单
- [ ] 剪切带位置、宽度
- [ ] 糜棱面理产状（倾向/倾角）
- [ ] S-C组构→确定剪切方向
- [ ] 拉伸线理产状（侧伏向/侧伏角）
- [ ] 鞘褶皱形态（素描XYZ三截面）
- [ ] 残斑类型（σ型/δ型）→旋转方向
- [ ] 糜棱岩化程度（初糜棱岩/糜棱岩/超糜棱岩）
- [ ] 标本（垂直面理+平行线理方向）

### 逆冲推覆记录清单
- [ ] 断层面产状
- [ ] 上盘地层（老）+ 下盘地层（新）
- [ ] 断层证据（角砾岩/擦痕/牵引褶皱）
- [ ] 飞来峰/构造窗的位置和规模
- [ ] 叠瓦状断片的排列方向
- [ ] 横剖面素描（标注地层+断层）
- [ ] 运移方向（从老地层分布→推覆方向）

## 常见坑
- S-C组构看反了 → S弯曲汇入C的锐角才是剪切方向
- 把沉积不整合当成逆冲面 → 不整合面上覆底砾岩、无擦痕
- 把石香肠当成断层角砾 → 石香肠是原位拉断（无位移），断层角砾有擦痕+错动
- 忘记了三维 → 韧性剪切带必须在XZ面（垂直面理∥线理）和YZ面（垂直面理⊥线理）都看
