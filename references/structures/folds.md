## 鉴定决策树

```

      │
      ▼
┌───────────────────┐
│ 1. 判断背斜还是向斜 │
│ 关键：看核部地层时代 │
└────────┬──────────┘
         │
    ┌────┴────┐
    ▼         ▼
 核部地层老   核部地层新
 背斜        向斜
    │         │
    ▼         ▼
┌───────────────────┐
│ 2. 判断是否倒转    │
│ 关键：看两翼产状   │
└────────┬──────────┘
         │
    ┌────┼────────┐
    ▼    ▼        ▼
 两翼倾向相反  两翼倾向相同  一翼倾角>另一翼
 倾角相近    但倾角不同
 直立褶皱    斜歪褶皱    倒转褶皱
    │    │        │
    ▼    ▼        ▼
 正常层序  正常层序   一翼倒转（需化石/沉积构造确认）
         │
         ▼
┌───────────────────┐
│ 3. 量参数          │
│ 两翼产状+枢纽产状   │
│ +转折端形态        │

         │
         ▼
```

## 背斜 vs 向斜 — 核部法（唯一可靠方法）

| | 背斜 | 向斜 |
|------|------|------|
| 核部地层 | **老** | **新** |
| 两翼地层 | 新 | 老 |
| 地层对称 | 核部老→两翼新 | 核部新→两翼老 |
| 未倒转时 | 岩层相背倾斜 | 岩层相向倾斜 |
| 倒转时 | 岩层同向倾斜 | 岩层同向倾斜 |

> **核心原则**：不要看岩层倾斜方向（倒转时会欺骗你），看核部地层时代！

## 褶皱要素

| 要素 | 定义 | 测量/记录方式 |
|------|------|-------------|
| **核部** | 褶皱中心部位出露的最老（背斜）或最新（向斜）地层 | 记录地层单位+岩性 |
| **翼部** | 核部两侧的岩层 | 记录各地层的代表性产状 |
| **枢纽** | 同一岩层面上最大弯曲点的连线 | 测枢纽产状（倾向/倾角） |
| **轴面** | 连接各岩层枢纽的面 | 描述轴面产状（直立/倾斜/水平） |
| **转折端** | 从一翼转到另一翼的弯曲部分 | 描述形态（圆滑/尖棱/箱状） |
| **轴迹** | 轴面与地面的交线 | 在地形图上标出 |

## 褶皱分类

### 按轴面产状

| 类型 | 轴面 | 两翼特征 |
|------|------|---------|
| 直立褶皱 | 近直立 | 两翼倾向相反，倾角相近 |
| 斜歪褶皱 | 倾斜 | 两翼倾向相反，一翼陡一翼缓 |
| 倒转褶皱 | 近水平 | 两翼倾向相同，一翼倒转 |
| 平卧褶皱 | 近水平 | 枢纽近水平，一翼在上 |
| 翻卷褶皱 | 弯曲 | 轴面弯曲 |

### 按枢纽产状

| 类型 | 枢纽 |
|------|------|
| 水平褶皱 | 枢纽近水平（倾角<10°） |
| 倾伏褶皱 | 枢纽倾斜 |
| 倾竖褶皱 | 枢纽近直立 |

### 按转折端形态

| 类型 | 转折端 |
|------|-------|
| 圆滑褶皱 | 圆弧形弯曲 |
| 尖棱褶皱 | 尖角弯曲 |
| 箱状褶皱 | 顶部平坦、两翼陡 |
| 挠曲 | 单斜中的台阶状弯曲 |

### 按翼间角（Ramsay 分类）

| 类型 | 翼间角 |
|------|--------|
| 平缓褶皱 | >120° |
| 开阔褶皱 | 70°-120° |
| 闭合褶皱 | 30°-70° |
| 紧闭褶皱 | 5°-30° |
| 等斜褶皱 | <5°（两翼近平行） |

## 褶皱野外记录格式

1. **褶皱名称**（地名+类型：如"牛背山背斜"）
2. **褶皱的地理位置和构造部位**
3. **核部地层**单位及岩性
4. **两翼地层**（从核部向外依次列出）
5. **代表性产状**

```
示例格式：
  核部 P2m 底部岩层产状 245°∠75°
  翼部 P2m 顶部岩层产状 240°∠35°
```

6. **枢纽产状**（倾向/倾角）
7. **轴面产状**
8. **转折端形态**
9. **褶皱规模**（波长、波幅）
10. **伴生构造**（次级褶皱、节理、断层）
11. **褶皱横剖面图** + **平面示意图**

## 峨眉山本地实例

### 牛背山背斜（路线一，D0202）
- **位置**：龙门硐电站附近
- **核部地层**：中二叠统（茅口组 P2m）
- **两翼地层**：上二叠统（峨眉山玄武岩 P2β）、下三叠统（飞仙关组 T1f）
- **特征**：直立背斜，轴面近直立，枢纽向北东倾伏
- **规模**：出露范围约数公里
- **关联构造**：南翼被回龙山断层切割

### 木鱼山向斜（路线三）
- **位置**：五显岗→清音阁之间
- **核部地层**：上三叠统垮洪洞组（T3k），出露于木鱼山
- **两翼地层**：下三叠统嘉陵江组（T1j）、中三叠统雷口坡组（T2l）
- **特征**：直立向斜，转折端平面圆滑，两翼对称
- **两翼倾角**：30°~40°，为直立对称向斜

### 牛背山背斜（二峨山段，路线五）
- **核部地层**：中二叠统
- **特征**：斜歪背斜，两翼均向东倾，倾角较陡

### 其他褶皱
- **桂花场背斜**：峨眉山背斜的次级构造，位于桂花场一带，枢纽波状起伏
- **张山背斜**：区域性背斜

## 常见坑
- **看岩层倾斜方向判断背斜向斜** → 倒转时反过来
- **不测枢纽产状** → 没法画剖面图
- **只测一两处产状** → 褶皱不同部位产状不同，必须多测
- **不分核部翼部** → 记录混乱
- **忘了在素描图上标地层代号和产状** → 张图废了一半
